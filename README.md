# AI Ingestion Pipeline

Production-grade asynchronous ingestion pipeline for AI startups, products, research papers, jobs, and news.

## Features

* Async web crawling
* GitHub metrics extraction
* LLM fallback orchestration
* Entity resolution
* Freshness tracking
* Scalable architecture

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
